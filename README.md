# Click Fixed (Geode)

Experimental practice assist for Geometry Dash.

Press **I** inside a level to open the menu and set **Fixed Jump: Yes / No**.

When enabled, if a click would kill you, the mod rewinds a few frames and replays the click
slightly later (up to ~0.1 s) until you survive. Only clicks that are too EARLY can be fixed.

Not for leaderboards or records: runs made with it are not legit.
